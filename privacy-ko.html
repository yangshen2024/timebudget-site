개인정보 처리방침

TimeBudget · 시행일: 2026-04-22 · 최종 수정: 2026-05-15

요약: TimeBudget은 아무것도 수집하지 않습니다. 입력하신 모든 정보(월급·위시리스트 등)는 사용자 기기에만 보관됩니다. 서버 없음, 분석 없음, 추적 없음, 광고 없음.

본 앱(이하 "TimeBudget" 또는 "앱")은 YANG SHEN(Apple Developer Team ID 27GPV267N2)이 개인 개발자 자격으로 개발·배포하며, 상품 가격을 필요한 근무시간으로 환산해 합리적 소비를 돕는 것을 목적으로 합니다.

1. 수집하는 정보

1.1 앱은 어떠한 개인 식별정보(PII)도 적극적으로 수집하지 않습니다.

1.2 설정 화면에서 사용자가 자발적으로 입력하는 데이터:

  • 국가 / 업종 / 직무 / 경력 연차
  • 월급, 일 근무시간, 월 근무일수
  • (선택) 사용자 지정 종합 세율
  • 위시리스트 항목 (이름 / 가격 / 통화)

1.3 위 모든 데이터는 오직 사용자의 기기 내 로컬 저장소(브라우저 localStorage 또는 iOS 앱 샌드박스)에만 저장되며, 절대 기기를 벗어나지 않습니다.

2. 정보 이용 목적

기기 내에서 "시급", "필요 시간", "세후 추정", "공유 카드" 등을 즉시 계산·표시하기 위한 용도로만 사용됩니다. 광고, 사용자 프로파일링, 머신러닝 학습, 상업적 배포 등 어떠한 다른 목적으로도 사용되지 않습니다.

3. 정보 공유 및 공개

어떠한 제3자에게도 사용자 데이터를 공유·판매·대여·공개하지 않습니다. 런타임에 외부 네트워크 요청을 발생시키지 않으므로, 데이터를 수신할 제3자 서버 자체가 존재하지 않습니다.

4. 제3자 SDK

없음. 분석, 광고, 푸시 알림, 위치, 결제, 소셜 로그인 SDK가 일절 포함되어 있지 않습니다.

5. 권한

iOS에서 앱은 어떠한 시스템 권한도 요청하지 않습니다(카메라·위치·연락처·마이크·앱 추적 권한 일체 없음).

Android에서는 기본적으로 INTERNET 권한만 선언하며, 이는 WebView 런타임이 로컬 오프라인 리소스를 로드하는 데에만 사용됩니다. 런타임에 실제 네트워크 요청은 발생하지 않습니다.

6. 보안 및 보관기간

데이터는 사용자 기기의 로컬 저장소에만 존재하며, 운영체제 및 사용자 기기 보안 설정에 의해 보호됩니다. 앱 삭제 시 자동으로 제거됩니다. 설정 화면의 "위시리스트 비우기" 또는 "기본값으로 재설정"을 통해 수동으로 데이터를 삭제할 수도 있습니다.

7. 아동 보호

본 앱은 만 13세 미만 아동을 대상으로 하지 않으며, 미성년자의 정보를 의도적으로 수집하지 않습니다.

8. 정책 변경

향후 네트워크 기능 또는 제3자 SDK가 추가되는 경우, 앱 내 눈에 띄는 위치에서 알리고 다시 동의를 요청합니다. 사용자는 언제든지 동의를 거부하고 사용을 중단할 수 있습니다.

9. 사용자 권리

사용자는 언제든지 다음을 수행할 수 있습니다:

  • 설정 화면에서 앱 내 모든 데이터 삭제
  • 앱 삭제를 통한 로컬 저장소 전체 제거
  • 아래 연락처로 문의 또는 권리 행사
